# 자동 분할 검증 목록 — 과거 실험

자동 배치 실험 코드는 현재 제거했습니다. 이 문서의 이전 체크리스트 대신 [현재 화면 정리 확인 항목](SCREEN_CLEANUP.md)을 사용하세요.

## 보존하는 확인 결과

- 시스템 창 바를 수동으로 드래그했을 때 두 앱을 나란히 표시한 POC는 성공했습니다.
- 공개 인접 실행 플래그 방식은 실제 AVD에서 실패했습니다. 플래그는 전달됐지만 두 앱 bounds가 같았고 FlowTrip은 숨겨졌습니다.
- 자신의 runtime portrait 요청/실측 대기 방식은 두 앱 자동 1:1 배치 성공으로 검증되지 않았고 현재 제거했습니다.

현재 확인할 것은 자동 분할 성공이 아니라 정리된 화면의 컴파일/레이아웃/버튼 기능과 수동 구성한 창 배치를 앱이 방해하지 않는지입니다. 이번 정리의 빌드·테스트·설치·실행은 수행하지 않았습니다.
