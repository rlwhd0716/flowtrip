# FlowTrip 5개 화면 이미지 자산 분리본

소스: 대화에서 생성한 메인 / 여행모드 입력 / 데이트모드 입력 / 여행모드 결과 / 데이트모드 결과 시안 5개.

## 폴더
- 01_backgrounds: 텍스트나 UI가 겹치지 않는 배경 사진 구간(6장)
- 02_place_photos: 장소 사진 및 썸네일 구간(12장)
- 03_icons_original_1x: 앱 영역의 아이콘을 화면에서 추출하고 배경을 투명 처리한 PNG
- 04_icons_upscaled_4x: 위 아이콘을 4배 확대(Lanczos)한 PNG. 새 디테일을 만들어낸 것은 아님
- 05_references: 5개 전체 시안, 비교 및 정확한 위치 확인용
- asset_manifest.csv: 각 이미지 원본 화면, 자르기 좌표와 제한사항
- preview_contact_sheet.png: 이미지 자산 빠른 미리보기

## 중요
생성형 UI 시안은 단일 래스터 스크린샷이며 원본 레이어/원본 고해상도 사진/벡터 아이콘이 별도로 존재하지 않습니다.
따라서 본 압축파일은 원본 자산을 복구한 것이 아니라 **실제 시안 픽셀에서 잘라낸 추출본**입니다.
- 텍스트가 겹친 배경은 텍스트가 없는 일부분만 잘라냈습니다.
- 인물/장소 이미지의 해상도는 시안에 그려진 픽셀 수준으로 제한됩니다.
- 아이콘 투명 처리는 색상 기준 자동 마스킹으로, 미세한 가장자리 손실 가능성이 있습니다.
- 앱 정식 리소스로 사용할 경우에는 원본 사진 교체와 벡터 아이콘 재제작을 권장합니다.
- AI로 생성한 풍경 및 장소 이미지는 실제 장소 사진으로 검증된 자료가 아닙니다. 실제 장소의 사진이라고 표시하면 안 됩니다.

## 개발 적용
위 파일을 Android `res/drawable-nodpi` 또는 `assets/`에 배치하고 `ContentScale.Crop` 및 크기 제한을 활용할 수 있습니다.
이미지 파일 이름은 ASCII 소문자 + 밑줄로 통일했습니다.
